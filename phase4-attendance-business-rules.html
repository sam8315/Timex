9. Late Decision

Definition

Late = Actual First Check-in > Scheduled Start + Grace Period

Example:
    Scheduled Start = 07:00
    Grace = 5 minutes
    Actual = 07:12

    Effective Deadline = 07:00 + 0:05 = 07:05
    Late = 07:12 - 07:05 = 7 minutes

Semantics Options

Option A: Only Violation Minutes 
Actual = 07:12
Scheduled Start = 07:00
Grace = 10 minutes
Late = 2 minutes (only the violation)
Cons: Loses information about total lateness
Option B: Total Late with Grace Flag (Recommended) 
Actual = 07:12
Scheduled Start = 07:00
Grace = 10 minutes

Total Late = 12 minutes
Grace Applied = 10 minutes
Late Violation = 2 minutes (excess)
Late Flag = TRUE (total > grace)
Pros: Preserves full information, Grace only controls the flag
Decision #7: Late Semantics

Question: Late چگونه گزارش شود؟

Recommended: Option B — ذخیره Total Late Minutes و Grace Applied. Late Flag از مقایسه مشتق شود.

Needs confirmation: YES

10. Early Leave Decision

Definition

Early Leave = Scheduled End - Grace Period > Actual Last Check-out

Example:
    Scheduled End = 14:00
    Grace = 10 minutes
    Actual = 13:50

    Effective Deadline = 14:00 - 0:10 = 13:50
    Early Leave = 0 (within grace)

Semantics

Actual = 13:50
Scheduled End = 14:00
Grace = 10 minutes

Total Early = 10 minutes (how early)
Grace Applied = 10 minutes
Early Violation = 0 minutes (excess)
Early Flag = FALSE (total <= grace)

11. Grace Semantics

Key Principle

Grace Period فقط برچسب Late/Early را کنترل می‌کند. Balance مستقل محاسبه می‌شود.

Example

Scheduled: 07:00 → 14:00 (7 hours required)
Grace: 10 minutes

Employee:
    Actual: 07:12 → 13:50

    Actual Work = 6h 38m
    Required Work = 7h 00m
    Balance = -22 minutes

    Late: 12 minutes total, 10 grace, 2 violation
    Early Leave: 10 minutes total, 10 grace, 0 violation

    Late Flag: TRUE (12 > 10)
    Early Flag: FALSE (10 <= 10)
Double Counting Prevention:

Late/Early فقط برچسب هستند. Balance از Work Hours محاسبه می‌شود. بنابراین Double Counting رخ نمی‌دهد.

13. Future Shift Compatibility

Abstraction Layer

class ReferenceTimeResolver(ABC):
    @abstractmethod
    def get_scheduled_start(self, employee, date) -> Optional[time]: ...

    @abstractmethod
    def get_scheduled_end(self, employee, date) -> Optional[time]: ...

class FixedTimeResolver(ReferenceTimeResolver):
    """Reads from AttendancePolicyDay"""
    def get_scheduled_start(self, employee, date):
        policy = resolve_attendance_policy(employee, date)
        weekday = to_jalali_weekday(date.weekday())
        day = policy.get_day(weekday)
        return day.start_time if day and day.is_working_day else None

    def get_scheduled_end(self, employee, date):
        policy = resolve_attendance_policy(employee, date)
        weekday = to_jalali_weekday(date.weekday())
        day = policy.get_day(weekday)
        return day.end_time if day and day.is_working_day else None

def resolve_attendance_policy(employee, target_date):
    employment_type = employee.department  # '1'-'5'

    # 1. Employee Override
    if employee.user_id:
        override = db.query(AttendancePolicy).filter(
            AttendancePolicy.user_id == employee.user_id,
            AttendancePolicy.is_active == True,
            # effective date check
        ).first()
        if override:
            return override

    # 2. Employment Type Policy
    if employment_type in ('1', '2', '3', '4', '5'):
        type_policy = db.query(AttendancePolicy).filter(
            AttendancePolicy.employment_type_code == employment_type,
            AttendancePolicy.user_id == None,  # Not employee override
            AttendancePolicy.is_active == True,
            # effective date check
        ).first()
        if type_policy:
            return type_policy

    # 3. System Default
    return get_system_default_policy()

18. Balance Decision

Formula

Balance = Actual Work Hours - Required Work Hours

Where:
    Actual Work Hours = Sum of daily work hours (from Attendance records)
    Required Work Hours = Sum of daily required hours (from Policy)

Component Analysis

ComponentEffect on BalanceNotes
LateIndirect (via Actual Work Hours)If late, work hours decrease → balance decreases
Early LeaveIndirect (via Actual Work Hours)If early, work hours decrease → balance decreases
OvertimePositive (Actual > Required)Balance > 0
Non-working DayOptional positiveIf employee works, hours count
LeaveZero Required WorkDay not counted in duty_days
HolidayZero Required WorkDay not counted in duty_days
Balance Rule:
  • Balance = Actual Work - Required Work
  • Late/Early NOT subtracted from Balance
  • Late/Early are informational labels only

22. Final Data Model

-- Attendance Policy (per employment type or employee override)
CREATE TABLE attendance_policy (
    id SERIAL PRIMARY KEY,

    -- Scope
    employment_type_code VARCHAR(10),    -- '1'-'5' (null for employee override)
    user_id VARCHAR(50),                 -- FK (null for type policy)

    -- Effective Date
    effective_from_date DATE NOT NULL,
    effective_to_date DATE,              -- null = currently active

    -- Late Policy
    late_enabled BOOLEAN DEFAULT FALSE,
    late_allowed_minutes INTEGER DEFAULT 0,
    late_reference_mode VARCHAR(20) DEFAULT 'FIXED_TIME',

    -- Early Leave Policy
    early_leave_enabled BOOLEAN DEFAULT FALSE,
    early_leave_allowed_minutes INTEGER DEFAULT 0,
    early_leave_reference_mode VARCHAR(20) DEFAULT 'FIXED_TIME',

    -- Status
    is_active BOOLEAN DEFAULT TRUE,

    -- Audit
    created_at TIMESTAMP,
    updated_at TIMESTAMP,

    -- Constraints
    CHECK (employment_type_code IS NOT NULL OR user_id IS NOT NULL),
    CHECK (late_reference_mode IN ('FIXED_TIME', 'SHIFT')),
    CHECK (early_leave_reference_mode IN ('FIXED_TIME', 'SHIFT'))
);

-- Weekly Schedule (per policy)
CREATE TABLE attendance_policy_day (
    id SERIAL PRIMARY KEY,
    policy_id INTEGER NOT NULL REFERENCES attendance_policy(id) ON DELETE CASCADE,

    weekday INTEGER NOT NULL,           -- 0=Sat, 1=Sun, ..., 6=Fri
    is_working_day BOOLEAN DEFAULT TRUE,
    start_time TIME,                    -- null if not working
    end_time TIME,                      -- null if not working

    UNIQUE (policy_id, weekday),
    CHECK (weekday BETWEEN 0 AND 6)
);

23. Final Business Rules

Rule 1: Employment Type Source

Employment Type = Employee.department با کدهای '1'-'5'.

Rule 2: Policy Resolution

اولویت: Employee Override → Employment Type Policy → System Default.

Rule 3: Required Work = Scheduled Span

Required Work Minutes = End Time - Start Time (بدون Break).

Rule 4: Weekly Schedule

هر روز هفته می‌تواند ساعت ورود/خروج متفاوت داشته باشد.

Rule 5: Non-working Day

Friday + Official Holiday + Policy Day (is_working_day=false) = Required Work = 0.

Rule 6: Holiday Override

Official Holiday اولویت بالاتری از Policy Day دارد. اگر Date = Holiday، Required Work = 0.

Rule 7: Leave

Approved Leave = Required Work = 0. فقط مرخصی روزانه پشتیبانی می‌شود.

Rule 8: Monthly Required Work

Monthly Required = Sum(Required Work of each duty day).

Rule 9: Balance

Balance = Actual Work - Required Work. Late/Early تأثیری ندارند.

Rule 10: Late

Late = Actual First Check-in - (Scheduled Start + Grace). اگر ≤ 0 → Late = 0.

Rule 11: Early Leave

Early Leave = (Scheduled End - Grace) - Actual Last Check-out. اگر ≤ 0 → Early Leave = 0.

Rule 12: Late/Early Independence

Late و Early مستقل هستند. فعال بودن یکی دیگری را فعال نمی‌کند.

Rule 13: Effective Date

Policy بر اساس تاریخ (نه سال) اعتبارسنجی می‌شود.

Rule 14: Duration Storage

مدت زمان به صورت Integer Minutes ذخیره می‌شود.

Rule 15: Future Shift

FIXED_TIME امروز، SHIFT در آینده. هیچ Shift Table ساخته نشود.
